# 人情村 · 美术阶段绘制方案 v2（按正式规格重写，待确认）

依据：《美术阶段：重做村庄场景》规格 + 六点确认答复 + 补充说明。确认后按第 9 节顺序逐类绘制，每类的 1× / 3× 图块表放在预览页里。

## 1. 画布与渲染

- 俯视 45°，tile 16×16，画布 24×22 tile = 384×352。按容器宽度取**整数倍**：< 768 为 1×（iPhone 14 两侧各留 3 px），768–1151 为 2×，≥ 1152 为 3×；`image-rendering: pixelated`。
- 一个 `<canvas>`，内部分 6 层各自离屏缓存：
  1. 地面层（草 / 路 / 田 / 石板 / 水底）——只在季节 / 时段变化时重绘
  2. 地面装饰层（落叶、花、影子）——同上
  3. 建筑与物件层（按底边 y 排序）——静态部分缓存；烟、灯笼摆动、水车这类动件单独画
  4. 角色层（按 y 排序，与建筑混排：人走到门前压住门，走到屋后被屋顶盖住）——每逻辑帧重画
  5. 光照层——夜晚亮窗 / 光晕 / 星星 / 萤火；时段变化才重绘
  6. UI 标签层——区域名、「+N」牌、心形气泡、选中态
- 水面 3 帧、烟 4 帧、树冠 2 帧、角色 4 帧，统一 8 fps 逻辑时钟；每帧只 `drawImage` 缓存层 + 重画角色层和动件矩形。`document.hidden` 时停表。
- 首屏：图块表预生成放到 `requestIdleCallback` 之外，首帧只需要地面 + 建筑两层（预计 < 60 ms），角色层第二帧补上。

## 2. 调色板与画法规范

- 48 色写在 `palette.ts`：16 色系 × 3 阶（基 / 暗 / 亮）。暗阶色相向紫蓝偏 8–15°、饱和度 +5、明度 −18；亮阶色相向黄偏 6–10°、明度 +14。基调偏暖，饱和度中等。
- 描边：基色所在色系再深两阶——三阶体系里就是「暗阶再往墨系借一阶」，所以每个色系额外指定一个**描边色**（从 48 色里另一色系的暗阶借，不新增颜色）：建筑 → 木暗 / 墨中，植物 → 春草暗 / 墨中，人物 → 墨中。表里逐色系标明。
- 抖动：只在水面、屋顶大面、天空边缘用 1:1 棋盘格，两色以内。
- 禁止：#000、#FFF、渐变、抗锯齿、半透明（见第 6 节昼夜的处理）。
- 每个图块画完先 1× 看能不能认出来，再看 3×。预览页图块表两种尺寸并排。
- 色系（具体 hex 在实现第 1 类时随色卡截图一起给，这里先定名称与用途）：墨、木、土路、石、砖红、白灰墙、青瓦、春草、秋草、雪、水、昼天、夜天、金（灯 / 麦）、粉（花 / 恋爱）、紫（帐篷）。

## 4. 素材清单与画法（每种怎么画）

### 4.1 地面（`sprites/ground.ts`）
- 草：每季 4 个纹理变体（草茬 2–3 簇，用基 / 暗两阶），随机铺，避免重复感。
- 土路：中心 + 8 方向边缘 + 4 个内角，边缘用土暗阶 1 px 描，路上撒 2–3 粒石亮点。
- 石板（广场）：2×2 tile 一组的板缝纹，缝用石暗阶，板面偶尔 1 px 亮阶反光。
- 田：垄 4 季（春嫩苗点、夏高株、秋金黄穗、冬雪垄），垄方向一致，垄沟用土暗。
- 雪：雪基阶铺底，雪暗阶做脚印 / 阴影点，屋顶边一条雪亮阶。

### 4.2 水系（`sprites/water.ts`）
- 溪：直段 / 45° 弯段 / 岸边 8 方向，水底土暗，水面基阶，波纹用水亮阶横线，3 帧循环平移 1 px；大面用棋盘抖动过渡到岸。
- 桥：木基 + 木暗板缝，两侧栏杆各 1 px，桥下一条影。
- 芦苇：3 变体，秋冬偏秋草色。
- 鸭子：8×8，2 帧游动 + 左右镜像，嘴橙、身白灰、眼墨；沿 4 点路径来回。
- 小船：靠码头，2 帧轻晃（上下 1 px）。
- 冬：溪边 1 tile 结冰（雪亮 + 水暗纹），中间仍流。

### 4.3 植被与小物（`sprites/flora.ts`、`sprites/props.ts`）
- 大树 2 形（圆冠 / 尖冠），2 tile 宽 3 tile 高，冠三阶 + 顶部亮块，树干木；四季 4 套（春粉花、夏深绿、秋橙红、冬秃枝顶雪）；2 帧摇动（冠边缘 1 px 左右）。
- 灌木 / 草丛 / 花丛（春粉黄多、夏白黄、秋橙、冬无）、石头 2、树桩、木箱、木桶、围栏直 / 角 / 门、路灯（夜亮）、告示板、稻草人、晾衣绳（衣服 2 帧飘）、南瓜（秋）、雪人（冬）、落叶片（秋）。

### 4.4 建筑（`sprites/buildings/*.ts`，一栋一个文件）
统一：4–6 tile 宽、4–5 tile 高（含屋顶）；墙有材质，屋顶有纹理，屋檐下一条暗阶阴影；门、窗；窗夜里亮；烟囱（工坊常冒，其他冬天冒）；门口 1–2 件专属小物。造型差异靠形体，屋顶按关系色只是辅助：

| 建筑 | 形体特征 | 墙 / 顶 | 专属小物 |
| --- | --- | --- | --- |
| 老宅 | 一层横长，正脊翘檐，门前三级石阶，院墙 | 白灰墙（斑驳点） / 青瓦 | 晾衣绳、水缸 |
| 我的家 | 一层带阁楼窗，屋前菜园 3×2，信箱 | 木板墙 / 屋顶色可换 | 菜园、信箱（有任务插旗） |
| 工坊 | 两段屋顶（主屋 + 侧棚），高烟囱，门是双开大门 | 砖墙（砖缝） / 蓝灰瓦 | 木料堆、铁砧、水车（临溪 3 帧） |
| 帐篷 | 圆锥紫帐，顶金穗，门帘半掀，门口小凳 | 紫布（竖条抖动） | 水晶球、黑猫（甩尾 3 帧）、灯笼 |
| 广场 | 井（石圈 + 木架 + 桶）、公告板、大树、长凳 ×2 | 石板地 | — |
| 茶馆 | 四角小亭，无墙，柱子 + 栏，挂幌子「茶」 | 木柱 / 橙瓦 | 两张矮桌 + 茶壶、灯笼 |
| 旅店 | 两层木楼，二楼外廊，门口挂「宿」牌 | 木板墙 / 木瓦 | 长椅、灯笼 ×2、马桩 |
| 湖边小屋 | 架在岸上的木屋，屋前码头伸进水，屋顶单坡 | 木墙 / 粉瓦 | 小船、钓竿、灯 |
| 村口 | 木牌坊「人情村」，两石狮改为两石灯，三级石阶 | 木 / 石 | 路牌、灯笼 |

### 4.5 角色（`sprites/chars/`）
- 16×24 正面小人：头 10×10（占上 10 行，压住上一格），身 8×8，腿 4 行。头大身小。
- 部件映射表 `charParts.ts`：脸 6 → 头形 / 下巴 2 px 差异；发 8 → 俯视发帘 + 后发块，各画一份；眼 → 2 px 眼点（眨眼帧闭合 1 px）；特征 → 眼镜 / 胡子 / 雀斑 / 皱纹小人版；衣 8 → 上身形（圆领 / V 领 / 背带 / 外套…）+ 1 px 图案；配饰 8 → 帽 / 围巾 / 发带 / 眼镜。颜色取 `AvatarConfig`，暗阶 `L−18% S+6%`，亮阶 `L+14%`，描边墨中。
- 1× 可辨：发型块 ≥ 8 px 宽且和肤色对比 ≥ 2 阶；衣服块 8×6 纯基色只加 1 px 亮阶；不在 1× 下画细节线。预览页「1× 辨识」视图把同一批人 1× 排成一行，先过这一关。
- 动画：待机 4 帧（起伏 1 px + 第 3 帧眨眼），行走 4 帧（腿交替 + 手臂 + 头 1 px 起伏），朝向 下 / 左 / 右 / 上（左由右镜像）。
- 行为：站门口；每 6–15 s 随机在本区可走格走 2–3 格再走回；点击 → 转向镜头 + 心形气泡 + 头顶心条 1.5 s → 进人物页。
- 灰化：坐姿剪影（8 帧全用夜天暗阶单色）+ 1:1 棋盘抖动做「半透明感」+ 头顶「…」气泡。**这是规格里唯一要求半透明的地方，我建议用抖动替代真半透明以守住规则，见第 8 节确认项。**
- 满心：头顶金星 2 帧。星婆婆：坐帐篷门口小凳，黑猫甩尾；「我」站菜园里。
- 点击区：所在 tile + 上一格 = 16×32，再外扩 6 px → 28×44；不足 44 时按 44 取；任何时候 ≥ 44 CSS px。

### 4.6 动效（`sprites/fx.ts`）
烟 4 帧（3 团往右上飘、渐小）、水 3 帧、树冠 2 帧、灯笼 2 帧摆、星星 2 帧闪（夜）、萤火 4 帧（夏夜，3–5 个）、蝴蝶 2 帧（夏昼）、落叶（秋，6 片沿斜线飘）、雪（冬夜 + 冬昼小雪，8 粒）。

## 5. 四季

按固定月份（3 / 6 / 9 / 12 月 1 日切换，用现有 `lib/season.ts`），设置里可强制季节（只影响场景与预览）。每季：地面色系 + 树 4 套 + 田 4 套 + 花丛开关 + 烟囱规则（秋起其他房子冒烟；冬全部冒）+ 粒子。

## 6. 昼夜

按六点答复采用**换色表**，不用半透明叠色：5 张 48 色对照表——清晨 05–07（偏橙淡）、白天 07–17（原表）、傍晚 17–19（橙红）、入夜 19–22（蓝紫、亮窗）、深夜 22–05（更深蓝紫、星多）。表之间在整点切换，不做渐变过渡（像素游戏的惯例是跳变；如果你要「平滑」，可以在边界前后各 10 分钟插入一张中间表，成本是多 2 张表）。
夜晚光晕：金暗阶一圈 + 夜天亮阶一圈（两圈），窗、灯笼、路灯、水晶球都用这套；星星用昼天亮阶 1 px 点闪；影子方向：清晨向左、傍晚向右，用地面装饰层的暗阶色块，不用半透明。

## 7. 交互

点建筑 → 从建筑处弹出像素小面板（该区村民：头像 + 心条 + 名字，点进人物页）；点村民 → 转向 + 心气泡 + 进人物页；点牌坊 → 全部名单；点帐篷 / 星婆婆 → 占卜屋（保留走进去的过场）；点我的家 → 我的档案；空地长按 / 点击 → 无反应。命中测试走 `hit.ts` 的矩形列表（建筑整块 + 人物 28×44），叠加时人物优先。
