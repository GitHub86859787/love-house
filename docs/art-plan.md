# 人情村 · 美术阶段绘制方案（待确认）

> 目标：把「一排房子」的横向场景换成一屏 24×22 tile 的分区小村；人物改为俯视小人；四季 + 昼夜按真实时间。
> 本文件是开工前的方案，确认后按「类别」逐类绘制，每类先出 1× / 3× 预览截图，看过再画下一类。

## 0. 画布与比例

| 项 | 值 | 说明 |
| --- | --- | --- |
| tile | 16×16 px | 全部地形、建筑、装饰按 16 的整倍数 |
| 地图 | 24×22 tile = 384×352 px | 一屏放完九个区域，不滚动 |
| 手机显示 | 1×，居中 | iPhone 14 宽 390，两侧各留 3 px |
| ≥ 768 px 宽 | 2× | 整数倍放大，不出现半像素 |
| 渲染 | 单个 `<canvas>`，`imageSmoothingEnabled = false` | 图块 / 精灵仍用现有 `Grid` 引擎画成离屏 canvas 缓存 |
| 帧率 | 8 fps 逻辑帧（`requestAnimationFrame` 节流） | 页面不可见时暂停 |

图层顺序（每帧重画）：地面 → 水（2 帧动画）→ 静物（建筑 / 树 / 栏杆，按底边 y 排序）→ 人物（按 y 排序，和静物混排以便走到房子前面 / 后面）→ 灯光（夜晚亮窗、水晶球光晕）→ 天气粒子（花瓣 / 落叶 / 雪，各 6–8 个像素点）。

## 1. 调色板（48 色，16 个色系 × 暗 / 中 / 亮 三阶）

规则：
- 每个色系恰好三阶；描边一律用**同色系的暗阶**，不用别的颜色描边。
- 没有 #000000 / #FFFFFF；最深是墨 `#2b1d14`，最亮是雪 `#eef3f6`。
- 不用渐变、不用抗锯齿、不用半透明叠色；明暗只靠三阶。
- 场景里出现的所有颜色都来自这 48 色。**人物**用头像生成器已有的部件色（皮肤 6 / 头发 10 / 衣服 8 / 配饰 8 / 眼睛 6），不占 48 色配额，但同样三阶 + 同色系描边（暗阶由中阶按固定表给出，见第 5 节）。

### 昼夜换色表

昼夜不做叠色滤镜，而是**四张 48 色对照表**：白天（原表）、清晨、黄昏、夜晚。每种颜色对应一个固定的替换色，仍是平涂。

| 时段 | 时间 | 处理 |
| --- | --- | --- |
| 清晨 | 05:00–07:00 | 整体偏冷偏淡（草、土向亮阶靠，天空用昼天亮阶） |
| 白天 | 07:00–17:00 | 原表 |
| 黄昏 | 17:00–19:00 | 草 / 土 / 墙向橙偏移一阶，天空用橙亮阶 |
| 夜晚 | 19:00–05:00 | 全部映射到夜天三阶 + 各色系暗阶；金色系**不变**（灯光） |

夜晚亮灯：每栋房子 1–2 扇窗改为金中阶，外圈一圈金暗阶（1 px），只做一层光晕，不做渐变。帐篷水晶球：金亮阶 + 外圈紫亮阶，2 帧闪动。

| 夏 | 春草暗 / 中阶为主 | 绿叶树 | 绿禾 | 水三阶 | 无（偶有蜻蜓 1 帧） |
| 秋 | 秋草三阶 | 橙叶树 | 麦穗（秋草 + 金） | 水中阶偏暗 | 落叶 |

## 4. 人物（俯视小人）

- 尺寸 16 宽 × 24 高（脚站在 tile 底边，头可越过上一格），贴合 16 px 地图。
- 部件与头像生成器**一一对应**：脸型 6 → 头宽 / 下巴形；发型 8 → 俯视发型（每个索引画一个小人版）；眼睛 → 2 px 眼点用眼睛色；特征（眼镜 / 胡子 / 雀斑 / 皱纹）→ 小人版；衣服 8 → 上身形 + 图案；配饰 8 → 帽 / 围巾 / 眼镜 / 发饰的小人版。颜色直接取自 `AvatarConfig`，同一个人两处颜色和部件完全一致。
- 人物色三阶：以配置色为「中阶」，暗阶 / 亮阶按固定 HSL 表推导（`darken(c) = L−18%、S+6%`，`lighten(c) = L+14%`），描边用暗阶。
- 动画：待机 2 帧（1 px 呼吸起伏）；走动 4 帧（双脚交替 + 手臂）；朝向 下 / 左 / 右（左由右镜像）/ 上。
- 行为：在自己地块的可走格之间随机走 1–3 格然后停 2–5 秒；鬼影（久未联系）走得慢、灰色；满心的人头顶金色小星 1 帧闪。
- 星婆婆同一套系统，站在帐篷门口，偶尔走到水晶球边。
- 点击命中区：小人所在 tile 及上方一格。

## 5. 预览页（隐藏）

路由 `#/preview`，不进导航，设置页「排盘自检」旁不加入口（只靠地址进）。功能：
- 季节四选一、时段四选一、也可勾「跟真实时间」；
- 放大 1× / 2× / 3×；
- 开关：网格线、区域边界与名字、动画、粒子；
- 假数据：每个区域塞 0–8 个随机小人，可调；
- 「图块表」视图：按类别把所有图块 / 精灵铺开，1× 与 3× 并排，每类一页，用来逐类验收；
- 导出当前画面 PNG。

## 6. 绘制顺序（每类先出 1× / 3× 截图，看过再画下一类）

1. 调色板 + 地面图块（含四季草地、路、田、石板、雪）
2. 水系（溪、湖、岸、桥、鸭子、冰面）
3. 植被与小物
4. 九处建筑（含夜晚亮灯版）
5. 人物小人（部件映射 → 待机 → 走动 → 三个朝向 → 星婆婆）
6. 四季 / 昼夜换色表、灯光、粒子
7. 场景组装与交互（点人、点区域、鬼影、金框、溢出牌、进帐篷过场）+ 预览页收尾

代码落点：`src/pixel/tiles/`（图块与静物数据）、`src/pixel/chars/`（小人部件）、`src/features/village/`（布局表 `layout.ts`、`palette.ts`、`renderer.ts`、`VillageCanvas.tsx`），旧的 `VillageScene.tsx` 在第 7 步整体替换；`model.ts` / `areas.ts` 不动（只把 `AreaId` 补上 `teahouse`，`deepen` 从广场挪到茶馆）。
